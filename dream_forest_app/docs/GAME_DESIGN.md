# 꿈나무 (가제) — 최종 기획서

> **한 줄**: 잠든 거대한 꿈나무를 **세로 화면에서 끝없이 오르는** 궁수. 손가락 하나로 좌우만 조종하면, 캐릭터는 **스스로 튀어 오르며 몬스터를 밟고 자동으로 쏜다.** 땅(발판)에 닿지 않고 이어갈수록 콤보가 커지고, 코인이 폭발한다. 층을 오를 때마다 스킬 카드를 골라 강해진다.
>
> **장르 공식**: 두들점프의 조작 × 궁수의 전설의 성장 × 슬리피 우드의 몽환적인 숲

---

## 0. 냉정한 전제

- "무조건 성공"은 어떤 기획으로도 보장되지 않는다. 차트 1위는 **기획 × 완성도 × 광고비·스토어 추천 × 타이밍**이 함께 맞아야 한다.
- 그래서 이 기획서의 목표는 두 가지다.
  1. **성공 확률이 가장 높은 구조**를 고른다.
  2. **돈과 시간을 크게 쓰기 전에 실패를 걸러내는 검증 단계**를 넣는다 (7장).

---

## 1. 자기 반박 기록 (어떻게 여기까지 왔나)

| 라운드 | 안 | 반박 | 결론 |
|---|---|---|---|
| 1 | 가로 횡스크롤 궁수의 전설 (지금 만든 것) | 위에서 보는 게임보다 **피할 공간이 적다**. 시점을 바꿔서 얻은 게 없다. 가로 화면은 **쇼츠·틱톡(9:16) 영상에 불리**하다 | ❌ 그대로 출시하면 "불편한 궁수의 전설" |
| 2 | 가로 유지 + 몬스터 물량 + 구르기 | 버튼이 늘면 진입장벽. 물량은 횡스크롤에서 피할 수 없어 억울함 | ❌ 조작 추가 금지 |
| 3 | 가로 유지 + 공중 콤보(밟기) | 중력이라는 횡스크롤의 무기를 쓴다 ✅. 하지만 가로 화면의 바이럴 약점은 그대로 | △ 콤보 아이디어만 살린다 |
| 4 | **세로 탑 등반** + 밟기 + 자동 사격 | 세로 한 손 플레이 ✅, 쇼츠 화면 그대로 ✅. 그런데 좌우 이동 + 점프 타이밍을 같이 하면 세로 화면에서 정밀 조작이 어렵다 | △ 조작을 더 줄여야 한다 |
| 5 | **자동 점프**(두들점프 방식) + 좌우 조종만 | 입력이 **좌우 끌기 하나**로 줄어든다 ✅. 반박: 자동이면 실력 요소가 없지 않나? → 착지 지점 고르기, 몬스터 머리 노리기, 탄 피하기, 위험한 길 고르기가 실력이다. 두들점프가 좌우 조종만으로 전 세계 히트를 친 게 증거다 | ✅ 채택 |
| 6 | 궁수의 전설의 "튕기는 맛"은? | 세로 탑은 **양옆이 벽**이다. 화살이 벽에 튕기는 **핀볼**이 자연스럽게 생긴다 ✅. 벽꽝도 그대로 산다 | ✅ 오히려 가로보다 낫다 |
| 7 | 물량과 회피 | 몬스터는 **발판 위에** 있다. 밟으면 죽고 나는 더 높이 튄다. 물량 = 밟을 발판 = 쾌감. 위험은 날아오는 탄과 가시 몹 소수로만 | ✅ 물량이 곧 재미 |
| 8 | 아래에서 차오르는 위협(악몽 안개)은 피곤하지 않나 | 계속 쫓기면 캐주얼 유저가 지친다 → 안개는 **아주 천천히**, 카드 고를 때·보스층·휴식층에서는 멈춘다. "멈출 수 없게 만드는 장치"로만 쓴다 | ✅ 약하게 |
| 9 | 끝없는 탑이면 금방 질리지 않나 | 탑은 **챕터(구간)**로 나뉜다. 100m마다 보스층, 중간에 상점층·휴식층. 챕터마다 배경·몬스터·장치가 바뀐다 | ✅ 리듬 |
| 10 | 바이럴은 어떻게 일어나나 | 영상 훅: "한 번도 발판에 안 닿고 몬스터만 밟고 30콤보 → 코인 폭발". 공유 훅: **오늘의 탑**(모두가 같은 탑, 하루 한 번 기록, 결과 카드 공유) — 워들처럼 매일 비교하는 맛 | ✅ 핵심 성장 동력 |
| 11 | 메이플 따라한 느낌? | 세로 탑 + 자동 점프 + 꿈 세계관이라 메이플과 겉모습·구조 모두 다르다. 몬스터는 잠·꿈·악몽 테마로 새로 짠다 | ✅ |
| 12 | 1인 개발로 가능한가 | 지금 코드의 물리·스킬·적 AI·연출·에셋 교체 시스템 대부분 재사용. 탑은 **조각(청크) 조합**이라 맵을 무한히 손으로 만들 필요가 없다. 그림·소리는 AI 일괄 생성 | ✅ 범위 관리만 잘하면 |
| 13 | "비슷한 게임이 이미 있다"면? | 점프+슈팅 탑 게임은 있을 수 있다. **출시 전 경쟁작 조사 필수** (7장 0단계). 우리 차별점은 카드 빌드 + 밟기 콤보 + 벽 핀볼 + 오늘의 탑의 조합 | ⚠ 반드시 확인 |

## 2. 핵심 재미 구조

### 2-1. 조작: 손가락 하나, 좌우만
| 입력 | 동작 |
|---|---|
| 화면 어디든 좌우로 끌기 | 공중에서 좌우 조종 |
| (아무것도 안 함) | 캐릭터가 **발판·몬스터에 닿으면 자동으로 튀어 오름** |
| 자동 | 가장 가까운 적에게 **자동 사격** (공중에서도) |
| 선택: 아래로 쓸기 | **급강하 밟기** (익숙한 사람용 보너스. 몰라도 깰 수 있음) |

- 세로 화면, **한 손 엄지**로 끝.
- 손을 뗀다고 멈추지 않는다 → "멈추면 쏜다" 대신 **"계속 쏜다, 대신 어디로 떨어질지 고른다."**

### 2-2. 손맛 (10초 단위)
- **밟기**: 몬스터 머리에 떨어지면 찌그러지며 터지고, 나는 **일반 점프보다 높이** 튄다. 히트스톱 + 진동 + 코인 튀어나옴.
- **공중 콤보**: 발판에 닿지 않고 몬스터만 밟아 이어가면 콤보 ×1, ×2, ×3… 배율이 오른다. 화면 테두리가 점점 빛나고 배경음 템포가 올라간다.
- **착지 = 정산**: 발판에 닿는 순간 콤보만큼 **코인이 분수처럼 폭발**하고 빨려 들어온다. (가장 중요한 "와" 순간)
- **벽 핀볼**: 탑 양옆 벽에 화살이 튕긴다. 튕길수록 세지고 빛난다 (지금 구현한 시스템 그대로).
- **벽꽝**: 넉백된 몬스터가 벽에 부딪히면 추가 피해.

### 2-3. 한 판 (3~5분)
```
출발 → 20m마다 [카드 3장 중 1장] → 50m 상점층(이번 판 코인으로 구매)
→ 100m 보스층(닫힌 원형 아레나, 보스 패턴) → 다음 구간(배경·몬스터 바뀜) → … → 떨어지거나 안개에 잡히면 끝
```
- **구간 구성** (자동 생성, 조각 조합): 일반층 70% / 위험층(가시·탄막) 15% / 보물층 10% / 휴식층 5%
- **떨어지면**: 화면 아래로 떨어지면 1회 부활(광고 보거나 보석). 아니면 끝.
- 결과: 높이(m), 최고 콤보, 코인, 새 도감 몬스터, 꿈 조각.

### 2-4. 하루 (재방문)
- **오늘의 탑**: 전 세계 모두 같은 탑(같은 시드). 하루 1회 공식 기록. 끝나면 **결과 카드**(높이·콤보·이모지 그래프) 공유 버튼 → 바이럴의 핵심.
- 출석 체크 7일 순환 (7일째 보석·스킨 조각)
- 일일 미션 3개 (예: "50콤보 달성", "보스 1마리", "슬라임 100마리 밟기")
- 무료 상자 (4시간마다)

### 2-5. 한 달 (장기 목표)
- **장비** 4칸: 활·망토·모자·부적. 같은 장비 3개 합성 → 등급 상승. (에셋 목록에 24종 이미 정의)
- **재능**: 코인으로 영구 강화 (지금 캠프 강화 확장)
- **도감**: 몬스터를 밟을 때마다 도감 경험치. 도감 레벨 보상 + 수집욕.
- **꿈나무 깨우기**: 기록이 오를수록 로비의 거대한 나무가 깨어나고 꽃이 피고 동물이 모여든다. (가벼운 꾸미기 = 아늑한 장기 동기 + 스크린샷 공유)
- **시즌 패스**(출시 후 2개월차): 무료/유료 트랙, 스킨 보상

## 3. 몬스터 구성 (물량은 쾌감, 위협은 소수)

| 종류 | 비중 | 역할 | 예시 (꿈 세계관, 메이플과 다른 디자인) |
|---|---|---|---|
| **밟기 몹** | 70% | 발판 위를 걷거나 떠다님. 밟으면 터지고 높이 튐. 닿아도 약하게 아픔 | 꿈젤리, 졸음 양, 베개 버섯, 솜구름 |
| **위협 몹** | 20% | 머리에 가시가 있어 **밟으면 안 됨**(쏴서 잡기). 또는 탄을 쏨. 반드시 ! 예고 | 가시 고슴도치, 악몽 박쥐, 포자 뿜개 |
| **정예 몹** | 8% | 체력 많고 보상 큼. 3번 밟아야 터짐 | 꿈먹는 맥(貘), 별 거북 |
| **보스** | 100m마다 | 닫힌 아레나에서 패턴 전투. 첫 처치 시 도감·장비 보상 | 잠꾸러기 젤리왕, 악몽의 군주 |

- 화면 안전장치: 동시 위협 탄 최대 6개, 동시 예고 최대 2개.
- 색으로 구분: **밟아도 되는 몹은 둥글고 밝은색**, **밟으면 안 되는 몹은 뾰족하고 붉은 테두리**. 한눈에 판단되게.

## 4. 스킬 (자동 발동만, 조작 추가 없음)

탑 구조에 맞게 재편. 기존 17종 중 대부분 유지 + 탑 전용 신규.

| 분류 | 스킬 |
|---|---|
| 화살 | 멀티샷, 사선, 관통, **벽 도탄**(핀볼), 연쇄, 화염, 빙결, 번개, 화살비 |
| 밟기 | **충격파 밟기**(밟을 때 주변 피해), **슈퍼 점프**(밟기 높이 +30%), **가시 무시**(가시 몹도 밟기 가능, 희귀) |
| 콤보 | **콤보 유지**(착지해도 1초간 콤보 유지), **황금 착지**(정산 코인 +50%) |
| 생존 | 나뭇잎 방패, 생명의 이슬, 흡혈, **날개깃**(떨어질 때 1회 자동 구조) |
| 탐색 | 자석, 꿈 조각 감지, 보물층 확률 증가 |

- 첫 카드는 항상 "체감 큰" 스킬 중 하나(벽 도탄 / 충격파 밟기 / 멀티샷)를 보장.

## 5. 난이도 설계

| 구간 | 목표 | 수치 목표 |
|---|---|---|
| 첫 60초 | **절대 실패하지 않음.** 밟기 3번, 콤보 1번, 카드 1장, 코인 폭발 1번을 반드시 경험 | 튜토리얼 탑은 바닥이 막혀 있음 |
| 첫 판 | 100m 보스까지 도달 | 신규 유저 60% 이상 첫 보스 도달 |
| 첫 주 | 매일 기록 갱신 | 평균 최고 기록이 매일 오름 (장비·재능 덕분) |
| 실패 직후 | 다시 하고 싶게 | "다음 강화까지 코인 N개 남음" 표시, 부활 1회 |

- **조각 단위 자동 검증**: 탑 조각마다 "자동 점프 + 좌우 조종"으로 다음 조각에 닿을 수 있는지 시뮬레이션 테스트 (지금 만든 도달 가능성 검사 방식 그대로 확장).
- **봇 밸런싱**: 봇이 수백 판을 돌려 높이별 사망률을 측정 → 몬스터 밀도·탄 속도를 자동 조정.
- **도움 장치**: 같은 구간에서 3번 연속 실패하면 시작 카드 1장 추가.

## 6. 바이럴 · 수익

### 바이럴 장치
1. **오늘의 탑 결과 카드** — 높이, 최고 콤보, 이모지 그래프. 탭 한 번에 공유. 링크로 들어오면 같은 탑에 도전.
2. **친구 대결** — 친구 기록 바로 위에 깃발이 보임 ("민지가 여기서 떨어졌어요").
3. **자동 하이라이트** — 그 판 최고 콤보 순간 5초를 자동 저장 → 쇼츠로 공유 (9:16 세로라 편집 없이 바로 업로드).
4. **랭킹** — 국가별·친구별 주간 랭킹.

### 수익 (첫 출시)
| 방식 | 내용 | 원칙 |
|---|---|---|
| 보상형 광고 | 부활, 코인 2배, 카드 다시 뽑기, 무료 상자 | **강제 광고 없음** (초반 이탈 방지) |
| 광고 제거 | 1회 결제 | |
| 보석 | 장비 상자, 스킨 | 실력보다 **편의·꾸미기 중심** |
| 시즌 패스 | 출시 2개월 후 | |
- 에너지(하트) 제한은 **넣지 않음**. 초반 바이럴 단계에서 플레이를 막으면 손해.

## 7. 출시 전략과 검증 게이트 (돈 쓰기 전에 실패 걸러내기)

| 단계 | 할 일 | 통과 기준 | 실패하면 |
|---|---|---|---|
| 0. 시장 조사 | 같은 공식(점프 탑 + 카드 빌드) 경쟁작 확인 | 정면으로 같은 히트작이 없음 | 차별점 재설계 |
| 1. 광고 소재 테스트 | 게임 완성 전, 15초 콘셉트 영상 3종으로 소액 광고 | 클릭률·설치 의향이 비교작보다 높음 | 콘셉트·영상 수정 |
| 2. 손맛 프로토타입 | 그래픽 없이 핵심 루프만 (2~3주) | 직접 + 지인 10명이 "한 판 더"를 자발적으로 함 | 핵심 루프 수정 |
| 3. 알파 | 3챕터, 장비, 출석, 오늘의 탑, 그래픽 교체 | 크래시 없음, 첫 판 보스 도달 60% | 난이도·튜토리얼 수정 |
| 4. 소프트 런칭 | 일부 국가에만 출시 | 다음날 재방문 40% 안팎, 7일 15% 안팎 (업계에서 흔히 보는 기준) | 숫자 안 나오면 광고비 쓰지 않음 |
| 5. 글로벌 출시 | 사전예약, 인플루언서, 광고 확대 | 광고비 < 유저당 수익 | 소재·수익 구조 조정 |

- 다국어: 한국어·영어·일본어·중국어(번체)·스페인어·포르투갈어부터. 글자가 거의 없는 게임이라 비용이 적다.
