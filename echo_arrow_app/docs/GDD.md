# 메아리 화살 (ECHO ARROW) — 게임 기획서

> 한 줄 소개: **"화살은 한 발씩. 그런데 과거의 내 화살들이 같은 순간에 다시 날아온다."**
> 세로 화면, 한 손가락, 글로벌 출시용 조준 퍼즐.

---

## 1. 게임의 정체성

| 항목 | 내용 |
|---|---|
| 장르 | 조준 + 물리 퍼즐 (스테이지 진행형, 하이브리드 캐주얼) |
| 조작 | 누르고 → 당기고 → 놓기. 장치(거울)는 톡. 버튼 없음 |
| 핵심 장치 | **메아리**: 실패한 화살은 사라지지 않고 다음 발에 같은 각도·같은 타이밍으로 다시 날아간다 |
| 차별점 | 퍼즐버블처럼 앞에서부터 순서대로 깨는 구조가 아님. 한 판에 풀이 경로가 여러 갈래(솔버로 갈래 수 측정)이고, 장치·스킬·메아리 조합으로 푼다 |
| 공유 포인트 | 클리어 순간 모든 화살이 동시에 날아가는 다시보기 = 그대로 쇼츠/틱톡 클립 |

### 1-1. 퍼즐버블 느낌을 피하는 설계 원칙
1. **순서 강제 금지**: 정령은 아무 순서로 맞혀도 된다. 막힌 앞줄을 치워야만 뒤가 열리는 구조는 만들지 않는다.
2. **풀이 갈래 2개 이상**: 솔버가 찾은 성공 각도 구간(갈래)이 1개뿐인 판은 보스 판에만 허용한다.
3. **세 가지 축으로 푼다**: 조준 각도 × 장치 조작(거울 회전) × 시간(메아리 타이밍). 후반일수록 세 축을 동시에 요구한다.
4. **역조건 퍼즐**: "맞혀야 하는 것"과 "맞히면 안 되는 것"(아기 정령)을 같이 배치해서, 1발은 피해 가고 2발은 맞혀야 하는 판을 만든다.

## 2. 코어 루프

```
[조준] 누르는 동안 시간 0.32배속, 메아리 재생
   ↓ 놓기
[비행] 튕김마다 음이 한 단계씩 올라감 → 명중 시 히트스톱
   ↓
 ├ 모든 정령 명중 → 슬로우모션 클리어 → 별/코인 → 다시보기/공유
 └ 실패 → 이 화살이 메아리로 남음 → 다음 발 (발 수 소진 시 이어하기 제안)
```

- 한 판 20~60초. 실패하면 0.3초 안에 다음 시도.
- 별: 기준 발 수 이하 ★3, +1발 ★2, 그 이상 ★1.

### 2-1. 손맛 장치 (플레이테스트 후 추가)
| 장치 | 내용 | 왜 |
|---|---|---|
| 정밀 조준 | 길게 당길수록 손가락 움직임 대비 각도 변화가 줄어듦 (감도 1.0 → 0.35). 크게 휘두르면 그대로 따라감 | 성공 폭 2~3° 판도 "내 손으로" 맞힐 수 있게 |
| 각도 표시 | 조준 중 활 옆에 −12.5° 같은 각도와 정밀 게이지 | 실패한 발의 각도를 기억하고 0.5°씩 고쳐 쏘는 "계획" 플레이 |
| 아깝다! | 내 화살이 정령 옆 13px 이내를 스치면 짧은 슬로우 + 정령이 화들짝 + "아깝다!" | 니어미스는 "한 번만 더"를 부르는 가장 강한 신호 |
| 트릭 메달 | 2번 이상 튕긴 화살로 깨우면 판마다 메달(+50코인), 지도에 표시 | 별 3개 이후에도 다시 할 이유, 실력 과시 |

## 3. 장치·스킬 목록과 등장 시점

| 요소 | 동작 | 퍼즐에서의 역할 | 첫 등장 |
|---|---|---|---|
| 나무 벽 | 튕김 | 기본 반사 | 1 |
| 이끼 | 화살 정지 | 길 차단 | 2 |
| 관통 | 정령을 꿰뚫음 | 한 발 다중 명중 | 3 |
| 버섯 범퍼 | 둥근 면, 맞는 자리에 따라 각도 변화 | 정밀 트릭 | 5 |
| 움직이는 정령 | 왕복 이동 | 타이밍 | 6 |
| **회전 거울** | 탭으로 45° 회전 | 플레이어가 지형을 바꿈. **메아리 경로도 같이 바뀜** | 8 |
| 방패 정령 | 한쪽 면은 튕겨냄 | 등 뒤로 돌아가기 | 11 |
| **아기 정령** | 맞히면 그 판 실패 | 역조건 퍼즐 | 12 |
| 분열 화살(스킬) | 첫 튕김에서 3갈래 | 자원 운용 | 13 |
| 얼음 | 한 번 튕기고 깨짐 | 상태 변화 + 메아리 순서 | 15 |
| 포털 | 같은 방향으로 순간이동 | 공간 연결 | 16 |
| 프리즘 | 3갈래로 분광 | 한 발 다중 경로 | 17 |
| 관통 화살(스킬) | 이끼를 뚫음 | 자원 운용 | 18 |
| **스위치·시간제 문** | 맞히면 문이 n초 열림 | 메아리 협동 | 20 |

### 3-1. 이후 월드 로드맵 (업데이트용, 월드당 20판)
| 월드 | 신규 요소 | 핵심 질문 |
|---|---|---|
| 6 바람 골짜기 | 바람 구역(화살 궤적이 휨) | 곡선으로 돌아가기 |
| 7 시계탑 | 시간 버튼(맞히면 3초간 모든 장치 정지) | 메아리 동기화 |
| 8 쌍둥이 정령 | 연결 정령(0.5초 안에 둘 다 맞혀야 함) | 분열/프리즘/메아리 동시 명중 |
| 9 색의 숲 | 색 정령(같은 색 메아리만 맞힐 수 있음) | 발 순서 계획 |
| 10 움직이는 거울 | 회전하는 거울·이동 벽 | 타이밍 + 지형 |
| 11 그림자 | 메아리만 통과하는 벽 / 현재 화살만 통과하는 벽 | 과거와 현재의 역할 분담 |
| 12~15 | 혼합 + 보스 판 | 모든 축 동시 |

### 3-2. 월드 내 20판 구성 (톱니형 난이도)
```
1  소개(새 장치 하나, 실패 불가 수준)
2~4  연습(새 장치 + 기존 장치 1개)
5  쉬어가기(쉬움, 코인 보너스)
6~9  응용(조합)
10 ★ 어려움(빨간 배지, 코인 2배)
11~14 비틀기(새 장치를 반대로 쓰기: 막는 장치를 길로 쓰기 등)
15 쉬어가기
16~18 복합
19 ★★ 아주 어려움(보라 배지, 코인 3배)
20 보스(월드 상자 보상, 다시보기 공유 유도)
```
- 난이도 지표 = 솔버의 **최적 배치 성공 각도 폭**(°)과 **필요 발 수**. 소개 판은 20° 이상, 어려움은 2~5°, 아주 어려움은 2° 미만 또는 3발 이상 협동.

## 4. 온보딩 (첫 10분)

원칙: **첫 30초 안에 첫 명중, 첫 3분 안에 첫 트릭샷, 첫 10분 안에 메아리 맛보기.** 메뉴는 필요할 때 하나씩 연다.

| 시점 | 열리는 것 | 연출 |
|---|---|---|
| 앱 실행 | 로고 없이 바로 1단계 | 손가락 가이드(당기기 애니메이션), 조준선 2단 표시 |
| 1단계 클리어 | 별/코인 연출만 | "다음" 하나만 보여 줌 |
| 3단계 클리어 | 홈(지도) 공개 | 지도 위 길이 그려지는 연출 |
| 4단계 | **출석 체크** 첫 수령 | 1일차 보상 자동 오픈 |
| 6단계 | 하트 시스템 시작 | 이전엔 실패해도 하트 차감 없음 |
| 7단계 | 부스터 공개 + 무료 3개 지급 | 첫 사용 강제 튜토리얼 |
| 8단계 | 상점 + **스타터 팩**(48시간 한정) | 한 번만 팝업 |
| 10단계 | 힌트 공개(무료 1회) | 막혔을 때 자동 제안 |
| 12단계 | 오늘의 한 발(일일 퍼즐) | 공유 문구 첫 노출 |
| 15단계 | 화살 패스(시즌) + 전면광고 시작 | |
| 20단계 | 메아리 연승 이벤트 | |

- 회원가입/로그인 없음. 닉네임은 공유할 때만 선택 입력.
- 튜토리얼 문구는 한 화면에 한 문장, 12자 내외 동사형.

## 5. 수익화 설계

### 5-1. 재화
| 재화 | 획득 | 사용 |
|---|---|---|
| 코인 | 클리어(★당 10, 어려움 ×2, 아주 어려움 ×3), 출석, 상자, 광고, 구매 | 이어하기, 부스터, 힌트, 하트 충전 |
| 하트 | 최대 5, 30분마다 1개 회복 | 판 시작 시 필요, **실패해서 판을 포기할 때만 1개 차감**(클리어는 무료) |
| 무한 하트 | 이벤트·패키지 | 시간제(30분~24시간) |
| 부스터 | 상자, 패스, 구매 | 판 시작 전/중 |

### 5-2. 과금 지점 (가장 중요한 것부터)
1. **이어하기**(발 수를 다 쓴 직후 = 과금 전환율이 가장 높은 순간)
   - +2발: 900 → 1,900 → 2,900코인(같은 판에서 오를수록 비싸짐). 메아리는 유지되므로 "거의 다 됐는데"라는 감정이 극대화됨
   - 하루 3회까지 보상형 광고로 +1발
2. **힌트**: 첫 화살 각도를 유령 화살로 보여 줌(솔버 정답 데이터 사용). 300코인 또는 광고 1회
3. **판 시작 전 부스터**(최대 3개 선택)
   - 긴 조준선: 반사 3번까지 표시 / 추가 화살 +1 / 분열 화살 1개
4. **스타터 팩**($1.99, 8단계): 코인 2,000 + 부스터 각 3 + 무한 하트 1시간
5. **광고 제거**($3.99): 전면광고만 제거, 보상형은 유지
6. **화살 패스**(30일 시즌, 프리미엄 $4.99): 별을 모으면 칸이 열림. 무료 줄 + 프리미엄 줄(활/궤적 꾸미기, 부스터, 코인)
7. **별빛 저금통**: 클리어할 때마다 코인이 쌓임(최대 5,000) → $2.99로 깨기
8. **코인 팩**: $0.99(500) / $4.99(3,000) / $9.99(7,000) / $19.99(16,000) / $49.99(45,000)
9. **꾸미기**: 활 스킨, 화살 궤적, 명중 이펙트. **다시보기 클립에 그대로 보이므로 과금이 곧 홍보**가 됨

### 5-3. 광고 규칙
- 전면광고: 15단계 이후, 클리어 3번마다 1회, 최소 간격 120초. 실패 직후에는 절대 노출 안 함(이어하기 제안과 충돌 방지).
- 보상형(선택): 이어하기 +1발, 힌트, 클리어 코인 2배, 출석 보상 2배, 하트 1개.
- 결제한 유저(누적 $1 이상)는 전면광고 빈도 절반.

### 5-4. 리텐션 장치
| 장치 | 내용 |
|---|---|
| 7일 출석 | 1일 100코인 → 7일 상자(부스터 묶음 + 꾸미기). **빠진 날이 있어도 초기화하지 않음**(이탈 방지) |
| 오늘의 한 발 | 전 세계 공통 일일 퍼즐, 워들식 이모지 공유 |
| 메아리 연승 | 첫 시도에 연속 클리어하면 다음 판 시작 시 무료 부스터(1→2→3연승). 실패하면 초기화 → 이어하기 결제 동기 |
| 오늘의 미션 | 매일 3개 (판 깨기 고정 + 날짜로 고른 2개: 별/트릭샷/메아리 명중/한 발 클리어/첫 시도/"아깝다" 듣기/별 3개). 3개 다 받으면 미션 상자. 8판 클리어 후 열림 |
| 월드 별 상자 | 월드마다 별 20·40·60개에서 상자 3개. 깬 판을 별 3개로 다시 하러 갈 이유 |
| 푸시 | 하트가 다 찼을 때, 출석, 연승 위기(옵션) |

### 5-5. 목표 지표 (소프트런칭 기준)
- D1 40%+, D7 15%+, D30 5%+ / 세션 길이 8분+ / 일 세션 4회+
- 결제 전환율 2~3%, ARPDAU $0.12+ (광고 포함)
- 바이럴: 공유 버튼 탭률 5%+, 공유 1건당 설치 0.3+

## 6. 화면 구성 (frontend-design 원칙 적용)

### 6-1. 디자인 방향
- 주제: **밤의 숲, 잠든 정령, 달빛 활.** 화면은 늘 밤이고, 게임 요소만 빛난다.
- 하나만 대담하게: **빛나는 궤적**(화살·메아리 트레일)이 이 게임의 얼굴. 나머지 UI는 조용하게.
- 템플릿처럼 보이는 것 금지: 모든 카드에 같은 둥근 모서리와 그림자를 쓰지 않는다. 대문자 라벨 남발, 가운데 정렬 남발도 쓰지 않는다.

### 6-2. 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| night | #10163F | 바탕 |
| dusk | #1B2462 | 패널 |
| moon | #FFD36B | 주요 행동, 현재 화살, 별 |
| echo | #7EF0FF | 메아리, 스위치 |
| moss | #6FD39B | 이끼, 성공 상태 |
| blossom | #FF9FC8 | 아기 정령, 경고 |
| ink | #EEF2FF | 본문 |

- 서체: 한글 **Jua**(둥근 손글씨 느낌의 제목/버튼), 숫자·라틴 **Fredoka SemiBold**. 본문은 시스템 서체.
- 크기 체계: 12 / 14 / 17 / 22 / 30 / 44.
- 간격: 4의 배수(4, 8, 12, 16, 24, 32).

### 6-3. UX 기준 체크리스트
- 모든 터치 영역 48dp 이상, 버튼 사이 간격 8dp 이상
- 본문 대비 4.5:1 이상, 큰 글자 3:1 이상
- 모든 화면에 빈 상태 / 로딩 / 오류 상태 정의
- 결제 버튼에는 가격과 받는 것을 함께 표기, 닫기 버튼은 항상 보이게(다크패턴 금지)
- 진동·소리 끄기, 모션 줄이기 설정 제공
- 한 손 조작: 주요 버튼은 화면 아래 1/3에 배치

### 6-4. 화면 구조 (상위 퍼즐 게임 공통 패턴)
```
┌ 상단 재화 바 (하트·타이머 / 코인+ → 상점 탭 / 설정) ── 모든 탭에서 고정
│
│  [상점]  ←스와이프→  [홈: 월드 지도]  ←→  [패스]  ←→  [도감]
│                     왼쪽: 이벤트(출석·오늘의 한 발·연승·스타터)
│                     오른쪽: 월드 진행 카드
│                     아래: 큰 초록 "N단계" 버튼
└ 하단 탭바 (가운데 홈 강조, 잠긴 탭은 자물쇠 + "N단계를 깨면 열려요")
```
- 팝업은 전부 가운데에서 튀어나오는 카드(리본 제목, 오른쪽 위 X, 바깥 누르면 닫힘). 결제·실패처럼 반드시 선택해야 하는 팝업만 X 없음
- 판 시작: 레벨 리본 → 이름·별·목표 → 부스터 3칸 → 초록 "플레이"
- 게임: 판 소개 카드(1.9초) → 조준 → 클리어 시 정령이 하늘로 날아가는 연출 → 전체 화면 축하(빛줄기·별이 하나씩 박힘·코인 카운트)
- 실패: "거의 다 됐어요!" 팝업(깨운 정령 수 표시) → 화살 +2(코인) / 광고 +1 / 처음부터 / 포기
- 클리어 후 홈으로 돌아오면 길이 금빛으로 이어지고 다음 단계 메달이 튀어나오는 해금 연출
- 탭 해금: 상점 7, 도감 10, 패스 14 (온보딩 순서와 일치)

## 7. 기술 구조
- Flutter + CustomPainter(게임 화면), 상태 저장 shared_preferences, 효과음 audioplayers.
- **결정론적 시뮬레이션**(`lib/game/sim.dart`): 1/240초 고정 스텝. 웹 솔버(`echo-arrow/sim.js`)와 같은 계산 순서를 유지하고, 테스트로 정답 데이터가 Flutter에서도 클리어되는지 확인.
- 레벨 데이터: `assets/levels/levels.json`(솔버 정답·난이도 포함). 새 레벨은 `tool/gen_levels.js`로 생성하고 솔버를 통과한 것만 넣음.
- 광고/결제: `lib/services/`에 인터페이스 + 목업 구현. 출시 전에 google_mobile_ads, in_app_purchase로 교체(키 필요).
- 분석: `Analytics.log(event, params)` 한 곳으로 모아 두고, 출시 시 Firebase 등에 연결.
