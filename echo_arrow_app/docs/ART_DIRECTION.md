# 메아리 화살 — 아트 디렉션

이미지는 Gemini로 일괄 생성한다. 이 문서는 모든 이미지가 **한 게임처럼 보이게** 하는 기준이다.
생성 목록과 프롬프트는 [ASSETS.md](ASSETS.md), 기계가 읽는 목록은 [asset_manifest.json](asset_manifest.json).

## 1. 한 문장
**"달빛이 비치는 그림책 속 밤의 숲. 잠든 정령들을 화살 한 발로 깨운다."**

## 2. 화풍
| 항목 | 기준 |
|---|---|
| 장르감 | 손으로 칠한 듯한 **동화 그림책 2.5D**. 부드러운 붓 질감, 둥근 형태, 두꺼운 외곽선 없음 |
| 빛 | 화면 밖 왼쪽 위의 **달빛(따뜻한 금색) 림라이트** + 게임 요소 자체의 **청록 발광**. 그림자는 남보라 |
| 채도 | 배경은 낮은 채도·어두운 남색, 게임 요소(정령·화살·장치)는 높은 채도·밝은 발광 → 배경과 요소가 한눈에 구분돼야 함 |
| 형태 | 둥글고 통통한 비율(머리 크고 몸 작게). 날카로운 각은 수정·거울 같은 장치에만 |
| 피해야 할 것 | 메이플스토리풍 도트/SD 캐릭터, 애니메 미소녀, 사실적인 3D 렌더, 네온 사이버펑크, 픽셀아트 |

## 4. 캐릭터
### 궁수 「루미」(Lumi)
- 남색 후드 망토를 쓴 작은 숲의 궁수. 얼굴은 크림색, 눈은 크고 까만 점 두 개, 볼 홍조
- 후드 끝이 고양이 귀처럼 살짝 솟음, 망토 끝에 달 모양 브로치
- 활은 **초승달 모양의 금빛 활**(활 자체가 은은하게 빛남)
- 성별이 드러나지 않는 귀여운 비율(2등신)

### 잠든 정령 「도지」(Dozy)
- 손바닥만 한 둥근 빛덩이. 토끼 귀 같은 작은 잎 두 장
- 잘 때: 하늘색 몸, 눈은 감은 곡선, 볼 분홍, 머리 위 'z'
- 깼을 때: 금색으로 변하며 눈이 웃는 곡선(^ ^), 작은 반짝임
- 아기 정령: 분홍색, 더 작음, 머리 위에 "건드리지 마" 표시(빨간 금지 동그라미). 맞으면 울상
- 방패 정령: 정령 한쪽에 은빛 반달 방패

| 월드 | 이름 | 풍경 | 대표 색 |

| 4 | 메아리 계곡 | 오로라가 흐르는 계곡, 떠다니는 룬 돌, 고대 석문 | 청록 + 보라 |

## 6. 게임 화면 배경 규칙
- 세로 1080×1920. **가운데 70% 영역은 어둡고 단순하게**(퍼즐이 잘 보이도록). 장식은 가장자리와 아래쪽에만
- 위쪽 15%는 HUD가 덮으므로 하늘
- 아래쪽에 궁수가 서는 작은 언덕/평평한 땅

## 7. 투명 배경 이미지 만드는 법 (중요)
Gemini는 투명 배경을 바로 못 만드는 경우가 많다. 그래서:
1. 프롬프트 끝에 **"on a solid pure green (#00FF00) background, no shadow on the background"** 를 붙인다 (ASSETS.md 프롬프트에 이미 들어 있음)
2. 받은 이미지를 `raw/` 폴더에 `<id>.png` 이름으로 저장 (예: `raw/spirit__sleep.png`, 슬래시는 `__`)
3. `python3 tool/process_assets.py raw/` → 초록 배경 제거, 여백 자르기, 크기 맞춤 후 `assets/images/` 에 자동 배치
4. `python3 tool/check_assets.py` → 빠진 것, 크기가 틀린 것 확인
5. 앱을 다시 실행하면 **이미지가 있는 것은 이미지로, 없는 것은 기존 코드 그림으로** 보인다 (하나씩 바꿔도 됨)

## 8. 일관성 체크리스트
- [ ] 모든 캐릭터·장치의 빛 방향이 왼쪽 위
- [ ] 정령과 화살이 배경보다 확실히 밝다
- [ ] 같은 종류끼리 크기 비율이 맞다 (정령 지름 = 궁수 키의 약 0.6)
- [ ] 글자가 들어간 이미지는 로고 하나뿐 (나머지 글자는 코드로 → 다국어 대응)
